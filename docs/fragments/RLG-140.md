### RLG-140 — A run can never start in a tunnel or on a bridge
- **RULED 2026-09-01T08:40:25-04:00** — RULED 2026-09-01 - Owner: "runs can never start in a tunnel or on a bridge", to be recorded
and implemented at the next break, and it should be simple.

IT IS REACHABLE TODAY. `openBiome` picks the first place of a run with a flat roll over
`BIOME_KEYS`, and every entry in the table is in that list - so one run in ten currently
begins already inside the bore, with the mouth behind the camera and no approach to it. The
bridge of [[RLG-112]] will join the same list the day it lands.

AND IT IS WRONG FOR A REASON THE RECORD HAS ALREADY WRITTEN DOWN. RLG-112 observes that a
tunnel and a bridge are not places at all: they are EVENTS with a mouth, a length and an
exit, where every other entry in the table is a place that lasts six to twelve miles at
random. Starting in one is not merely unusual, it is starting in the middle of a thing that
has a beginning. [[RLG-105]] built the tunnel's entrance as a ramp on the biome crossing
precisely so that arriving is a passage rather than a cut, and a run that starts inside
skips the whole of it.

THE ANSWER IS A STATED PROPERTY, NOT A NAME THE PICKER KNOWS. This project has now removed
the same shape three times - the horizon form that fell through to towers and gave farmland
a city ([[RLG-102]]), the silhouette colour that tested for TUNDRA, and the rock palette
that was a boolean ([[RLG-104]]). A picker that reads `if(k === 'TUNNEL' || k === 'BRIDGE')`
is a fourth, and it is wrong on the day a fourth event place is added. The place should say
that it cannot open a run - one field, read by `openBiome` and by nothing else.

WATCH THE SECOND CALLER. `openBiome` is not the only roll: the running game picks the next
place the same way when the current one ends, and that one must keep every entry - the whole
point of a tunnel is that you drive into it. So the exclusion is on OPENING a run, not on
choosing a place, and a fix that filters `BIOME_KEYS` itself would delete the tunnel from the
game. There is a third caller in the debug API that cycles places by hand; it should keep
reaching everything.

AND MOTORSPORT IS A SEPARATE QUESTION. A circuit sits in ONE place for the whole race rather
than driving through them, so a circuit in a tunnel is a race with no sky for five laps. The
owner said "runs", which is Interstate's word. Ask before extending it, or take the same
field and let the circuit builder read it too - the second is probably right and it is not
what was asked for.
- **RULED 2026-09-01T08:50:12-04:00** — BUILT 2026-09-01, v0.11.6, and it was as simple as the owner said.

MEASURED BEFORE AND AFTER, ON THE ENGINE'S OWN DRAW. 35 of 400 opening rolls landed in the
tunnel before this - about one run in eleven, which matches the flat roll over ten places -
and none of 400 does now.

`passage` IS THE PROPERTY AND IT IS STATED BY THE PLACE. A tunnel says it is a thing you
enter and leave rather than one a run can open in; the bridge of [[RLG-112]] states the same
field the day it lands and needs no second edit. That is the fourth name branch this file has
avoided or removed in two versions, after the horizon form, the silhouette colour and the
rock palette in [[RLG-104]].

THE CARE IS ALL IN THE SECOND LIST, and the fragment named it before the work started. There
is one list of places, and the running game picks the NEXT one from it while you drive - so
filtering THAT list would make the tunnel unreachable and delete it from the game. `OPEN_KEYS`
is a second list read by `openBiome` and by nothing else, so the rule is about OPENING a run
rather than about choosing a place.

AND THE CHECK READS BOTH HALVES, because a check on the opening draw alone cannot tell
"excluded from opening" from "deleted from the game". `tools/tunnel-test.py` asserts that the
tunnel is absent from the opening list AND present in the full one, and it samples the draw
itself rather than the list: `pickOpening` is the function `openBiome` calls, so the harness
reads the engine instead of a copy of it.

BOTH FAILURE MODES WERE PUT BACK AND WATCHED GOING RED. With `OPEN_KEYS` set to the full list
the sampling check failed at 35 of 400. With the full list filtered instead, the reachability
check failed and the opening check went on passing - which is exactly the pair of results
that shows the two assertions are measuring different things.

MOTORSPORT GETS IT TOO, AND THAT WAS NOT ASKED FOR. The owner said "runs", which is
Interstate's word, but a circuit takes its place from the same `openBiome`, so a race can no
longer be held in a tunnel either. That is very probably right - a circuit sits in ONE place
for the whole race, so a tunnel circuit is five laps with no sky - and it is recorded here
rather than assumed, because the owner may want a tunnel circuit as a deliberate thing.
