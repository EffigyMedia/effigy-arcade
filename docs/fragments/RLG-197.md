### RLG-197 — LORRY becomes SEMI, with a migration for saves that hold the old key
- **RULED 2026-09-09T21:06:23-04:00** — **Owner, 2026-09-09:** *"I would like to rename the Lorry to Semi since I am an American."* And,
confirming the two words mean the same vehicle: they do, for THIS vehicle. "Lorry" is the British
general word for a truck; the thing drawn here is a tractor unit pulling a box trailer, which is
precisely what American English calls a semi. The rename loses nothing.

**IT IS NOT A SEARCH AND REPLACE, BECAUSE THE KEY IS PERSISTED.** The chosen car is written into the
save BY KEY. Rename the body and the lookup misses, the fallback runs, and anybody who was driving a
lorry is silently put into a ROADSTER - not a cosmetic loss, but somebody's car, chosen in a garage,
replaced without a word.

**SO THERE IS A MIGRATION, AND IT HAS A PRECEDENT.** `FORMULA` became `APEX` when the one formula car
became three, and that is one line doing the same job. Both now live in one `RENAMED` table read where
the save is loaded. **A migration is not a thing to remove later**, because the save it repairs may
not be opened for a year.

**PROVED BY `tools/rename-test.py`, AND FALSIFIED FIRST.** It writes the OLD key into a save, reloads,
and asks the engine which car it is in - so a migration that did nothing would answer ROADSTER and one
that ran on the wrong key would answer with the wrong car. With the `LORRY` entry removed the harness
reports exactly that: *opened ROADSTER*. Restored, both keys open the car they named.

**IT IS A HARNESS RATHER THAN A READ-THROUGH FOR ONE REASON.** A migration is dead code on every run
except the one that needs it. Nothing else in the suite would notice if it were deleted, mistyped, or
moved above the line that overwrites it.

**WHAT MOVED WITH THE KEY:** the `BODY` entry, its player-visible note, `BODY_CLASS`, `PLAIN_WHEEL`,
the thin-rim wheel test, `WORK_BODIES`, the two class tables in the debug API, the fleet-sheet body
list and its trailer-paint test - and eight harnesses that name the car. The internal rig is still
`truck`, which is correct: that is the SHAPE the painters draw, it is already American English, and it
is shared with the traffic lorries that have no body key at all.
