### RLG-195 — The lawbreaker is an OUTLAW and the competitor is a RACER
- **RULED 2026-09-09T19:36:26-04:00** — **Owner, 2026-09-09:** *"We need to rename the racer personality to outlaw and the rival personality
to racer."*

**THE OLD NAMES DESCRIBED TWO DIFFERENT THINGS WITH ONE WORD, AND THE WRONG WAY ROUND.** `RACER` was
a personality a CIVILIAN DRIVER can have on a public road: somebody driving their own car as fast as
it will go, in traffic, among people who are not racing. The cars you actually race - on a circuit,
in a tournament - were `rival`. So the game called the lawbreaker a racer and the competitor
something else, in a product that has both on the same road.

OUTLAW is what that driver IS, and it leaves `racer` free to mean what everybody assumes it means.

**NOTHING ABOUT BEHAVIOUR CHANGED.** Same target speed, same merge urge, same edge, same spawn odds,
same lane discipline. This is a rename and it is recorded as a chore for that reason.

**WHAT MOVED:**

| was | is |
|---|---|
| `RACER` (the personality constant) | `OUTLAW` |
| `'racer'` in the personality counts | `'outlaw'` |
| `RIVAL_BODIES`, `RIVAL_SP`, `RIVAL_FRONT_SP`, `RIVAL_STRIPES` | `RACER_*` |
| `rivalFront`, `rivalBodies` | `racerFront`, `racerBodies` |
| `row(r, 'rival')` in the debug rows | `row(r, 'racer')` |

**TWO USES OF THE WORD WERE DELIBERATELY LEFT.** "a KART RACER does need them" is about a kart racing
game and not about a personality. `COUPE - THE QUICKEST THING THAT IS NOT A RACER` is a car's note,
which the player reads, and it means "not a race car" - which is MORE correct under the new naming
rather than less.

**THE HISTORICAL PROSE STILL SAYS `rival` IN ABOUT A HUNDRED AND SIXTY COMMENT LINES, AND THAT IS
DELIBERATE.** Many of them quote an owner ruling verbatim, and a mechanical sweep would falsify the
quotes while producing a diff nobody could review. The prose that sits ON a renamed declaration was
updated so the code reads consistently at the point of use. If the rest is ever wanted, it is a
separate mechanical unit with a human reading each hunk.

**AND THE RENAME NEEDED THE HARNESSES IN THE SAME COMMIT.** `mind-test.py` reads the personality
counts by key, so it moved with the engine; the first run after the rename failed with `KeyError:
'outlaw'` because three objects still declared `racer:0` where the counter had been renamed. Every
other harness turned out to read `R.racers` - the race-opponent array, whose name was already right -
and needed nothing. mind-test, racer-test, smoke and drive all pass.
