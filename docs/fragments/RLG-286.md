### RLG-286 — Fuel leaves Interstate and stays in the code for Motorsport
- **RULED 2026-09-16T23:56:58-04:00** — TRACKED, NOT STARTED. Owner, 2026-09-16: "As much as I like the fuel gauge. Let's take it out of interstate - but we will need it for Motorsport so keep it in code. Let's do the same for the Gerry can."

IT IS A CFG SEAM, NOT A DELETION, AND THE OWNER SAID SO IN THE SAME BREATH. "Keep it in code" is the whole instruction: `road.js` serves both driving games and must not know which one is running except through `CFG` (CLAUDE.md, architecture). So this is a switch Interstate sets and Motorsport does not, and every line of the fuel model stays exactly where it is.

THREE THINGS GO BEHIND THE SAME SWITCH, and they have to go together or the game contradicts itself: the fuel GAUGE in the HUD, the fuel BURN that drives it, and the JERRY CAN pickup that refills it. A can on the road that refills a tank nothing reads is a pickup that does nothing; a gauge with no burn is a dial that never moves - the decoration this project's own rule forbids ([[RLG-081]]: a dial that is not fed by anything).

WHAT TO CHECK WHEN IT IS BUILT. `drive-test.py` asserts fuel today and covers BOTH games, so it has to ask each game for what that game has rather than assert fuel unconditionally - the same shape `circuit-test` already uses for what a circuit must NOT have. And the jerry can is one of the pickups RLG-266 lays, so the count it lays changes with this.

AND IT IS A TUNABLE WITH A COMMITTED DEFAULT, not an edited-in-place constant.
- **RULED 2026-09-17T07:31:35-04:00** — BUILT, v0.14.74. One switch, `CFG.fuel`, gates the fuel dial and the jerry can together. It is off unless a game sets it, and Interstate does not set it. No fuel code was deleted: the dial painter, the pump lamp, the can's sprite, its spawn row and its clock payout are all unchanged.

WHAT THE DIAL WAS. In Interstate the "fuel gauge" was the RUN CLOCK drawn as a dial (RLG-240), and the jerry can paid clock seconds. So removing both removes no fuel model. The number countdown stays on the HUD, and the checkpoints still pay time.

FOR MOTORSPORT, WHICH HAS NOT SET THE SWITCH YET. It keeps its own tank in `motorsport.html`. When it wants the dial, it sets `fuel` and passes `CFG.fuelFrac`, and the dial reads that tank rather than the race clock. A game that passes `fuelFrac` shows the dial whenever it drives, because a tank does not depend on a clock. Pickups stay off on the circuit through `circuitOnly`, as before, so the can would need that rule revisited too.

A CONSEQUENCE THE OWNER SHOULD KNOW. The can was a source of clock time. RLG-100 records that a ROADSTER at full throttle runs out of clock before its first checkpoint. That margin is now smaller.

`API.crateKinds().live` now reads each pickup's own `live` rule rather than restating it, so a check and the spawner cannot disagree.

PROVEN. fuel-gauge-test: Interstate draws no dial with the clock counting, the cluster is the two-dial height, and the dial's five original checks pass with the switch on. pickup-test: fuel is dead with the clock on in both default arms, and with the switch on the can is live and is laid. Falsified by making `fuelOn()` ignore the switch: two checks failed in each harness. crate-test and smoke-test pass. drive-test is 36/37; the failure is the nitrous-settle line, which failed before this unit.
- **RULED 2026-09-19T07:09:57-04:00** — REVERSED AND REDESIGNED, owner, 2026-09-19. Shown that removing the can had drained the timed run (RLG-100: every sports car lost about 0.7 s of clock per second at full throttle), the owner said: "bring the fuel gauge and the can back. My only concern was that it was weird earning fuel at checkpoints." On realism: a clock picked up off the road would be non-diegetic, and a can is no less realistic than a NOS bottle or a toolbox.

Then, choosing between one system and two: "I like the checkpoints because it's reminiscent of older games like Cruis'n USA and OutRun. But I also like the fuel idea because the fuel gauge looked good. The can looks good and it makes sense but we don't need both systems."

THE RULING: ONE SYSTEM, AND CHECKPOINTS ARE FUEL STOPS. The fuel gauge is the timer. A gantry refuels the car, which keeps OutRun's cadence and makes the refill make sense, and a jerry can tops it up on the road. The number countdown goes, because it was the second display of the same quantity. Chosen over "fuel only, gantries for show" and "clock only, no fuel".

UNDERNEATH, NOTHING CHANGES IN THE ARITHMETIC: the quantity is still the run clock, a gantry still pays its class's seconds (RLG-235), and a can still pays 10. What changes is what the player is told it is. Motorsport keeps its own tank and its race clock, and the switch stays off there.
- **RULED 2026-09-19T07:53:29-04:00** — TAKEN BACK, owner, 2026-09-19, while the fuel-stop build was being checked: "Stop. I take it all back. Let's leave it checkpoints and use clocks as the pick up. We'll still leave the fuel gauge and refueling for motorsport." And: "I don't wanna overcomplicate things for half diegetic implementations."

THE RULING NOW. Interstate has NO fuel: no gauge, and checkpoints pay time on the number countdown, as OutRun did. The pickup that pays time is a CLOCK, not a jerry can - the owner's earlier point that a clock off the road is non-diegetic is set aside on purpose, because the alternatives were half-diegetic systems that cost more than they gave. The fuel gauge and refuelling belong to Motorsport.

WHAT WAS DISCARDED: the uncommitted fuel-stop build of UNT-370 (tank as timer, FUEL STOP gantry, capped tank, fuel wording, lit dial, fuel-stop-test). None of it was committed or pushed. The EVD records of its checks stay as history. The committed `CFG.fuel` switch from v0.14.74 stays: it keeps the dial and the fuel model available to Motorsport, off in Interstate.
