### RLG-323 — The racers use every stripe version, every random colour and every underglow
- **RULED 2026-09-21T22:39:35-04:00** — OWNER, 2026-09-21: 'And I want to make sure all the stripe versions, random colors, and underglows are being used by the racers.' (The message said 'undergoes'; underglow is the only reading that fits a car's livery.)

A VERIFICATION FIRST, then a fix if it finds a gap. The question is whether the racer generator can reach every stripe variant, every paint in the random pool and every underglow colour the garage offers - or whether some of them exist only for the player. It is the fleet rule seen from the livery side: a rival is not a lesser car, and it should not be a plainer one either.

THE PROOF IS A TALLY, not a reading of the source: spawn many grids and count which stripe, paint and underglow each racer got, against the full list each table declares. Anything that is declared and never drawn is the finding. Not started.
