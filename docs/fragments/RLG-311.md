### RLG-311 — A tournament is saved per car, and can be retired and started again
- **RULED 2026-09-21T00:17:04-04:00** — OWNER, 2026-09-21: 'It may be odd to let a player switch cars in the middle of a tournament because the car and total tournament time gets recorded on the leaderboard. The simplest solution is have a tournament save PER car. There should be a way to start a tournament over (retire the previous one).'

THE OWNER HAS NAMED BOTH THE FAULT AND THE FIX. A tournament's result is a car and a total time, and today one save can hold a run that was driven in two cars - so the row on the board names a car that did not drive all of it. The answer is a tournament save PER CAR, and a way to RETIRE the one in progress and start again.

THREE THINGS THIS TOUCHES, read once and not yet tested:
- THE SAVE KEY. A tournament save today is one record; per car it is keyed by body. [[RLG-197]] is the standing rule on this and it is not optional: a body key is persisted, so renaming a car needs a migration, and a MIGRATION IS NEVER REMOVED. Splitting one record into many is the same class of change and needs the same care - an existing half-finished tournament has to land somewhere sensible rather than vanish.
- THE CAR CHANGE ALREADY HAS A GUARD AND IT POINTS THE OTHER WAY. There is a note about keeping `tourRound` alive when a car change drops the mode, 'so that a half-finished tournament' survives. That was written to protect the single save. Per-car saves make it unnecessary and possibly wrong, so it is read before it is kept.
- RETIRING IS A DESTRUCTIVE CONTROL and this product has one other - the save eraser. It needs to ask, and it needs to be reachable from wherever a tournament is resumed.

AND IT SITS ON A CARD THAT IS ABOUT TO BE REBUILT. [[RLG-210]] rebuilds the garage card and [[RLG-213]] already put a class-cycling button on it; [[RLG-223]] is the menu overhaul. A retire control is a fourth control on the same surface, so the four are designed together or they arrive as four separate additions to one card.

[[RLG-292]] is the local leaderboard and is the reason this matters now - a board is what makes a wrong row visible.

Not started.
