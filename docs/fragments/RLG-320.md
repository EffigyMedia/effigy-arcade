### RLG-320 — Survey which places are railed on which sides, and which lost a rail they need
- **RULED 2026-09-21T19:22:56-04:00** — OWNER, 2026-09-21, having found the swamp railed on one side only: 'I wonder if that's happening in other biomes that don't need to be removed.'

THE HISTORY THAT MAKES THIS A FAIR SUSPICION. [[RLG-264]] deleted roadside furniture that stood in mid-air, and [[RLG-265]] then put guard rails back ONLY at the limit of travel - on the side a place declares a hazard, or both sides for the city. Every other side has no rail, and the car still stops at `edgeX()` either way: 'a side with no rail is not a side you can drive off'. So an unrailed side is by design wherever the ground simply continues. Whether each place's design matches what the owner expects has never been listed.

WHAT IS WANTED IS A TABLE, NOT A FIX: every place, which sides carry a rail, why, and what lies beyond each one - so the owner can mark the ones that are wrong. `API.edgeOf(key, side)` answers the rail and `hazardSideOf` the hazard, so the table is derivable from the engine rather than read from the code by hand.

Not started.
