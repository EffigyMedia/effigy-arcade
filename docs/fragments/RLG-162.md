### RLG-162 — The wanted level is heat POINTS, and it can fall to empty

Owner, 2026-09-07: "I feel like your wanted level should be more granular. So
instead of a single instance of something raising it one star, we could do heat POINTS -
and every instance of speeding where a new cop sees you speeding, or you being directly
responsible for a cop getting destroyed, or you running a roadblock, adds to these points.
Cooling off removes these points, so your wanted level can go down to empty as well."

THE CURRENT MODEL IS AN INTEGER FROM ONE TO FIVE that moves in whole steps and floors at
one. Under this it becomes a POINT TOTAL: earned in instances, spent by cooling, and able
to reach zero - which the current model cannot, so there is at present no such thing as
being clean.

THE EARNING EVENTS THE OWNER NAMED: a new cop seeing you speed, being responsible for a
cruiser going down, and running a roadblock. Note "a NEW cop" - the same cruiser watching
you speed for a minute is one instance, not sixty.

Pairs with RLG-163, which is how the points are shown. Also flagged in UNT-193: the
ladder check had to stop asserting dispatch counts and should be revisited once this
lands, because the dispatch rate becomes a function of a smooth number rather than a step.
