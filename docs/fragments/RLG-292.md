### RLG-292 — A local leaderboard: record times for every mode
- **RULED 2026-09-19T16:01:54-04:00** — OWNER, 2026-09-19, answering what a drag race records: 'best time per car. But also, we should be recording times for everything, like a little local leaderboard.' So every mode keeps local times - a small leaderboard on the device, per machine (EVERY MACHINE OWNS EVERYTHING IT STORES: the key goes under effigyarcade.<id>.<what>.v1 and into smoke-test's saves() check). What 'a time' means differs by mode - a drag race is a time over one mile, a circuit race a race time and laps, an endless run a distance - and which of those the board shows, how many entries it keeps and where it is seen are not decided. The owner said to finish drag racing first and come back to this. Not started.
- **RULED 2026-09-20T00:13:01-04:00** — SPECIFIED BY THE OWNER, 2026-09-19/20.

WHAT A BOARD KEEPS, PER MODE, AND EACH MODE HAS ITS OWN FORM:
  TEST DRIVE - the score is the DISTANCE DRIVEN, and it has a board PER STATE. A state is the set of switches the run was driven under: checkpoints (the clock) and hot pursuit. So four states - both on, pursuit only, checkpoints only, neither - and each keeps its own board.
  SINGLE RACE - the time it took to finish the race.
  TOURNAMENT - the total time to finish the tournament.
  ALWAYS WITH THE CAR, and the player PUTS IN A NAME for an entry.

WHERE: a LEADERBOARD button on the TITLE screen, opening a board with its own buttons to pick the mode, and inside a mode another layer of buttons for the state.

BOTH DRIVING GAMES, BUT DIFFERENT, AND MOTORSPORT IS NOT A CONCERN NOW: build it on Interstate; the engine keeps the board and each machine stores its own (EVERY MACHINE OWNS EVERYTHING IT STORES).

STILL TO DECIDE: how a name is entered (arcade initials tapped in, or a text field), how many entries a board keeps, and whether a drag race - which already keeps a best per car (RLG-156) - appears as a mode on the board.
- **RULED 2026-09-20T00:14:18-04:00** — DECIDED, owner 2026-09-20: a name is ARCADE INITIALS - three letters tapped in with arrows, no keyboard. Each board keeps TEN, and the name is asked only when a run makes the ten, so an ordinary run ends as it does now. DRAG RACE is a fourth mode on the board, with the car and the time; the best-per-car it already keeps (RLG-156) becomes its entries.
- **RULED 2026-09-20T02:47:52-04:00** — BUILT, v0.14.98, WITH ONE CHECK OUTSTANDING - committed as a checkpoint before a machine restart, and the outstanding check is a HARNESS question rather than a known defect.

WHAT IS BUILT. A LEADERBOARD button on the title screen opens the modes; a mode opens its board, and TEST DRIVE opens its four states first. Boards: drive (per state, the DISTANCE driven, higher is better), race, tour and drag (TIME, lower is better); drag is offered only where drag racing is (dragOffered). Ten entries each, kept sorted in the board's own direction. An entry is three initials tapped in with arrows - no keyboard on a touch-only product (RLG-002) - the car, and the score. The name is asked ONLY when a run makes the ten, so an ordinary run ends as it did.

THE CLOCK IS EVERY RUN'S NOW: the drag race's dragT became runT, counted from GO for every run, and a tournament adds its rounds into tourT. A test drive offers its distance at showEnd, the one door a wreck and the clock both come through; a single race offers runT at its finish; a tournament offers tourT at the trophy; a drag race offers runT before its own card.

TWO FAULTS FOUND AND FIXED WHILE TESTING. (1) After the initials the board's BACK walked into the board MENU instead of the run's end card, so  was never cleared and THE NEXT RUN SKIPPED ITS OFFER - the second test-drive state recorded nothing. Each board screen now carries its own way back, and the flag is cleared when a run starts rather than on the way out. (2) The store is  and is registered in smoke-test's saves() list.

PROVEN so far by tools/board-test.py, driving real runs: the title offers it; all four modes and all four states are there; an empty board says so; a drag race that makes the board asks for initials and stores the letters entered, the car and the race's own time, and announces 1ST; two test drives under different switches wrote TWO boards (drive:cp 0.225 MI and drive:cp+hp 0.226 MI).

OUTSTANDING: the last check - 'a run that does not place asks for nothing' - fails, and it is not yet known whether the harness reached the end card at all (its diagnostic print was not applied before the restart). RESUME THERE.
