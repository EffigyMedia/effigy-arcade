But also, we should be recording times for everything, like a little local leaderboard.' So every mode keeps local times - a small leaderboard on the device, per machine (EVERY MACHINE OWNS EVERYTHING IT STORES: the key goes under effigyarcade.<id>.<what>.v1 and into smoke-test's saves() check).
