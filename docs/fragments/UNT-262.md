### UNT-262 - The harness waits for the engine, not for the document

- Routing class: `build` -> **claude-sonnet-5**, effort **medium**. Bias 1. Packaging and toolchain work against a known target. ([[RLG-092]])
- Opened for: [[RLG-208]]
- Opened by `unit.py`. **The identity exists before the first edit** ([[RLG-097]]), so the snapshot has somewhere to go.
- **CLOSED 2026-09-10T20:39:37-04:00** - The harness suite waits for the ENGINE now, not for the document (RLG-208), and the change is twice the size the ruling described. The ruling named 110 `goto` call sites; there were 104, plus 108 `wait_for_function` polls and 6 `reload(wait_until="load")` calls - 218 in all across 100 harnesses. The polls were the half that mattered most: the ruling itself records that form timing out at 20 seconds on the wedged machine while a single `evaluate` answered at once, so converting the `goto` alone would have moved the hang four lines down.

Three helpers in `harness.py`. `boot(page, url)` navigates on `commit` and waits for the engine, with the URL deciding which engine so a call site needs no second argument. `until(page, expr)` is the Python-side poll that replaces `wait_for_function` - one round trip at a time, so the page's own animation loop cannot starve it. `reboot(page)` is the same for a reload. All three raise by default, because every call they replace raised, and they raise with a READING of the page rather than a timeout.

Measured while the machine was still wedged: smoke-test 6/6 where it had been 4/6, drive-test 37/37 where neither driving cabinet could be reached at all. The proof is `tools/boot-proof.py`, which MAKES the wedge rather than waiting for one - its own server holds an image request open forever - and asserts the negatives as well as the positives.

The mistake worth keeping: five harnesses already had a wrapper called `boot`, and the conversion turned the helper's call inside them into the wrapper calling itself with the wrong arity. drive-test went from 37 checks to a TypeError. They import it as `engine_boot` now, and the proof asserts no harness shadows a name it imports - watched failing with the defect put back.

Not signed off (RLG-116), so RLG-208 is in-flight. EVD-627 is a step that never ran - a bad interpreter path, exit 127; EVD-628 is the same proof run correctly. `wait_for_selector` was deliberately left alone: Playwright polls that one in the page too, but nothing has measured it starving.
