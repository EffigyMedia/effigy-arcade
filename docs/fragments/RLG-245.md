### RLG-245 — The engine's build stamp and the shell's version are checked for agreement
- **RULED 2026-09-13T17:48:43-04:00** — FOUND AND FIXED. Owner, 2026-09-13: `window.ROAD_BUILD` in road.js drifted to 0.13.70 while `A.version` in arcade.js reached 0.13.84. The road.js comment says the stamp is "bumped with Arcade.version, in the same commit, every time", and nothing enforced it.

**WHY IT MATTERS.** `Arcade.buildTag()` prints MIXED when the two stamps differ. The tag exists to catch a fresh shell beside a cached engine, because `sw.js` serves scripts network-first with a cache fallback. With the stamps drifted, every device read MIXED for fourteen versions. The one signal for a half-cached build was always on, so it told the owner nothing.

**THE DRIFT.** The owner places it after f4e3110 (2026-09-09), which bumped both stamps to 0.13.70. History is not linear there: 9618cf58 on a working branch also carried a one-version gap (0.13.67 against 0.13.66). The RLG-171 fix commit bumped both stamps to 0.13.85 by hand. Both stamps read 0.14.17 when this unit opened.

**THE CHECK, IN THREE PLACES.** A disagreement in the source is always a missed bump, never a stale cache, so it fails the gate:

    pack.sh           after the sw.js version check, in --check and in a build. It reads both stamp lines with sed, fails when either line is missing, and names both versions.
    smoke-test.py     a `stamps` row that reads the source. It runs for any selection of cabinets and needs no browser.
    smoke-test.py     inside each cabinet, `Arcade.buildTag()` must not contain MIXED. This tests the effect on the page, not the text of the files.

**THE PROOF.** `tools/stamps-falsify.py` copies the tracked product into a temp root, drifts the stamps there, and asserts each check fails: road.js lagging (the drift that shipped), arcade.js lagging, and a missing stamp line. It also asserts that pack.sh refuses on the stamps and not on another gate, and that `--check` writes nothing. `--browser` also runs smoke on a drifted copy and asserts the MIXED tag is caught. EVD-816: all 14 assertions pass. EVD-818: smoke passes on the real tree, 7 of 7.

**WHAT THE PROOF CANNOT CHECK.** It does not show that a real device reads MIXED for a real stale cache. No harness here reproduces a half-cached pair of scripts.

**A SEPARATE DEFECT, NOT FIXED HERE.** EVD-817 records `pack.sh --check` exiting 1 on the real tree with "games.js does not evaluate". It is not this change: HEAD's pack.sh fails the same way. Node throws EISDIR on stdout inside `$(...)` when Python launches bash with the tree on the P: drive. The same run from a shell passes, and the sandbox copy on C: passes. Until it is fixed, `step.py` cannot record a pack.sh run from this tree.

**NO VERSION BUMP AND NO CHANGELOG ENTRY.** Nothing that ships changed: pack.sh and tools/ are not in the cache lists, and the rebuild left assets.js and sw.js unchanged.
