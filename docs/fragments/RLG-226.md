### RLG-226 — The working cars get the working knob, and both games now say so

**RULED 2026-09-12.** Owner, on being shown the hole [[RLG-225]] left behind: *"Yes fix the
production and utility gear knobs, but we need a better classification of cars officially."* The
first half is this ruling. **The second half is [[RLG-227]] and is not built.**

---

## TWO FAULTS, ONE SYMPTOM

`WORK_BODIES` decides which cars show a moulded black gear knob with white text instead of the
sports car's polished ball. [[RLG-069]], owner 2026-08-30: *"I also want production and utility
vehicles to have a black leather or plastic shifter with white text on it."*

**1. THE LIST NAMED SIX BODIES AND THE FLEET HAS EIGHT WORKING ONES.** The AMBULANCE was added after
the list was written and nobody came back to it - the same omission [[RLG-225]] had just found in
`PLAIN_WHEEL`, in a second list, an hour earlier. The HATCH is newer still, and it is a production
car beside the SALOON and the COUPE, so there was never a reading of the ruling that left it out.

**2. ONLY INTERSTATE CARRIED THE STYLE.** `road.js` toggles `body.workknob` in both games, because
the engine does not know which of the two is running. Only `interstate.html` had a rule for that
class. **That was correct until [[RLG-213]]**: production could not race, so no car that wanted a
black knob could reach a circuit. Production is a race class now, `raceOnlyGarage` lists it, and a
SALOON arrived on the grid holding a polished ball while the same car on the interstate held a
moulded one. Same car, same control, two finishes depending on which cabinet you opened.

Measured rather than assumed: `garageBodies()` in Motorsport returns STALLION, MATADOR, VECTOR,
APEX, COMET, ROADSTER, TUNER, MUSCLE, COUPE, HATCH, SALOON and CREST. **The three production cars
are in the circuit garage on `main`.**

> **THE OWNER SAYS THE CIRCUIT HOLDS ONLY SPORTS, SUPER AND FORMULA "like before" (2026-09-12), AND
> THE BUILD SAYS OTHERWISE.** The most likely reading is that the device is right about the build it
> is running: the deployed version is **v0.13.89** and [[RLG-213]] landed across v0.13.88 to
> v0.13.93, so the phone has the old garage. If instead it is a ruling that production must not race
> on the circuit, then `RACE_BANNED` gains a row and the Motorsport rule added here becomes harmless
> rather than necessary. **Put to the owner; not decided here.** The knob rule is correct under both
> readings, which is why this shipped without waiting.

## WHAT CHANGED

`WORK_BODIES` is eight: COUPE, SALOON, HATCH, CAB, PICKUP, VAN, SEMI, AMBULANCE. Motorsport gained
the `body.workknob` rule, written for the class rather than for the three bodies in it.

**THE LIST IS STILL HAND-WRITTEN AND IS NOT DERIVED FROM `BODY_CLASS`, DELIBERATELY.** Today the
working cars are exactly the `production` and `traffic` classes, so deriving it would be one line.
`BODY_CLASS` is the **unlock** class, and binding a steering column to it means a decision about
what a car COSTS silently changes what it is made of. [[RLG-213]] is the first place those two
questions had to be asked apart, and the owner has now asked for the split to be made properly
([[RLG-227]]). Deriving the list now would bake in the coupling the next ruling exists to remove.

## THE PROOF

`tools/knob-test.py`, new, and it runs **both games**.

It measures the RENDERED KNOB. Asserting AMBULANCE is in `WORK_BODIES` would test the fix against a
copy of itself, and asking the page whether `body.workknob` is set would test the class name rather
than the control the player sees. So it sets each body through `API.setBody` and reads the computed
background, border and number colour off `#knob`.

**THE ORACLE IS `BODY_CLASS`, WHICH THE CHECK NEVER WRITES.** A body whose class is `production` or
`traffic` must show the working finish; everything else keeps the polished ball. `WORK_BODIES` is a
separate list in the engine and the check fails the day the two disagree - **which is what lets the
engine keep its own list safely until the classification lands.**

1. **The two finishes are different**, in each game, read off a VAN and a STALLION. Without this,
   every other question passes on a cabinet with no working-knob rule at all - exactly the state
   Motorsport was in.
2. **All 19 bodies wear the finish their class demands**, in each game.

`--falsify knob` serves the engine with HATCH and AMBULANCE struck back out: question 2 fails in
**both** games, naming `AMBULANCE(traffic), HATCH(production)`. `--falsify circuit` deletes the
`body.workknob` rule out of Motorsport's live stylesheet: question 1 fails there and the interstate
still passes. **Both were watched failing before this was written down.**

The circuit falsifier deletes the rule from the live document rather than serving a rewritten
cabinet. Rewriting it over the network was the first attempt and the navigation hung - **a cabinet
registers a service worker, so the page HTML is not reliably a request Playwright gets to answer.**
That is worth keeping: it will bite the next harness that tries to serve a cabinet.

## WHAT IS NOT DONE HERE

The police cars still keep the polished ball. That remains a decision rather than an oversight, on
the same reasoning [[RLG-069]] recorded: the force is a class of its own. Unchanged, and one entry
if the owner wants it.
