### RLG-339 — One time of day choice is RANDOM, and it is the default
- **RULED 2026-09-24T11:57:46-04:00** — OWNER, 2026-09-24: "I'd like one of the time of day choices to be random and that should be the default."

TWO PARTS, AND BOTH ARE STATED PLAINLY. A RANDOM entry is added to whatever the time-of-day option offers, and RANDOM becomes the value a machine starts with when nothing has been chosen. The second half is the one with a consequence: it changes what a NEW player sees on their first run, and it changes what every existing save sees only if they have never touched the setting.

WHAT RANDOM HAS TO MEAN IS THE ONE QUESTION. Rolled once when the run starts is a different game from rolled once per place - the first gives a run an hour and keeps it, the second makes the hour part of the scenery. The owner said "one of the time of day choices", which reads as a value the option can hold rather than a behaviour that changes during play, so a roll at the start of each run is the reading to build unless the owner says otherwise.

AND IT MUST NOT ERASE A CHOICE. A player who has set a time of day keeps it. Only a machine with nothing stored takes RANDOM.

NOT STARTED.
