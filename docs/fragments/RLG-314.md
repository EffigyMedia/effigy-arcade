### RLG-314 — A bust ends the run and the end card does not say BUSTED
- **RULED 2026-09-21T08:21:52-04:00** — FOUND 2026-09-21, NOT REPORTED BY THE OWNER. `tools/bust-ends-test.py` fails one check: 'and the end screen says BUSTED', and the card it read said 'TEST DRIVE · CHECKPOINTS + PURSUIT'.

IT IS PRE-EXISTING AND IT IS NOT RLG-305. Found while running the suite for that change, and then run against the commit before it, v0.14.115, which fails the identical check with the identical text. Every other check in that harness passes on both builds: the run ends when the bar completes, it ends with time still on the clock, it happens once rather than over and over, and an ordinary wreck still costs seconds rather than the run.

SO [[RLG-267]] IS HALF DONE. That ruling is marked built, and its behaviour is right - a completed busted bar does end the run now. What the player is TOLD is not: the card carries the run's mode line, which is what the card would say for any other ending, rather than the reason this one ended.

FIRST READING, NOT A DIAGNOSIS. `showEnd(reason)` takes the reason as its argument and puts it in the eyebrow, and `wreck('BUSTED')` passes it. So either the reason is being dropped on the way - a second path to the card that does not carry it - or the harness is reading the wrong element. The second has to be ruled out first: this record carries several harnesses that asserted against the wrong part of the page, and the standing lesson is to suspect the check when it fails.

Not started.
