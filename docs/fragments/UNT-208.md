### UNT-208 - Stars belong to a clear night, and a tundra can have an aurora

- Routing class: `feature` -> **claude-sonnet-5**, effort **medium**. Bias 1. Implementation to a spec that already answers the design questions. ([[RLG-092]])
- Opened by `unit.py`. **The identity exists before the first edit** ([[RLG-097]]), so the snapshot has somewhere to go.
- **CLOSED 2026-09-08T05:19:33-04:00** - The ruling said to measure before changing anything and the measurement decided it: a clear sky and a nine-tenths overcast one put out the same star count, because the alpha never mentioned the cover. It does now, there are 110 stars rather than 40, and a clear sky has no cloud in it at all. The aurora is a moment rolled once per tundra at one in four, night only, clear sky only, hanging down from a ragged edge. The harness asserts the aurora and prints the star numbers, because with the gate removed the star ordering still held - cloud covers a star as well as dimming it, and a check that cannot fail is worse than none.
