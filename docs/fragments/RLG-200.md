### RLG-200 — A place lasts four miles
- **RULED 2026-09-10T03:22:13-04:00** — TRACKED, NOT STARTED. Owner, 2026-09-10: "biomes should last 4 miles."

**WHERE IT IS.** `placeSpan` is the one line that decides: a place declares an optional `span` in
MILES, and every place on the board is absent today except the tunnel, so the default rules
everything. That default is `rnd(6.5, 12) * MILE` - between six and a half and twelve miles, rolled
per place. Four miles is a flat number in the same units, and the edit is one expression.

**IT IS A ONE-LINE EDIT AND NOT A ONE-LINE CHANGE.** A place is the unit several other systems hang
on, and shortening it by two thirds shortens all of them at once:

    weather ends with the biome ([[RLG-017]]), so a shorter place means shorter weather and more
    changes of it per run;

    the biome sweeps toward the player rather than cutting ([[RLG-022]]), and the sweep is sized
    against the place it is arriving into;

    the tunnel already OVERRIDES the default with its own `span`, because at interstate speed a
    rolled length ran two and a half to four and a half minutes underground and could outlast the
    run it appeared in. Four miles is close to the length a tunnel was capped to, which is worth
    checking before assuming the two numbers can stay independent.

**AND FOUR MILES IS ABOUT NINETY SECONDS** at the speed the road is actually driven, against a run
clock that starts at sixty and is bought back at checkpoints. That is roughly one place per clock,
where it used to be one place per two or three. Whether the road then reads as varied or as
restless is a judgement on a device and not a number a harness can settle.

**WHAT TO MEASURE.** `API.placeSpan(k)` already reports what a place STATES against what the engine
ARMS, in miles - so the change is provable without driving. `biome-test.py` and `scenery-test.py`
are the two harnesses that read places.
