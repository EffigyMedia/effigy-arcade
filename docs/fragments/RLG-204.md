### RLG-204 — copLivery is assigned and never read
- **RULED 2026-09-10T03:22:14-04:00** — TRACKED, NOT STARTED. Found while building [[RLG-181]], not reported by the owner.

**THE RULE IS WRITTEN, THE STATE IS SET, AND NOTHING READS IT.** `copLivery` carries a comment
stating a real design decision: *"A force does not run half its cars in white and half in black on
the same night. The livery is chosen once when the run starts and every cruiser wears it - including
yours, so there is no 'player version' and 'NPC version', just the cars that are out tonight."* The
variable is declared at the top of the file and assigned in exactly one place, when a run resets. It
is read NOWHERE. `COP_PAINT`, the table beside it, is read by one sprite dump and nothing else.

**SO THE FORCE'S COLOUR IS DECIDED AT BOOT AND NOT PER RUN.** The cruiser and the interceptor sprites
are built once with fixed values, which is why the rule reads as if it works: the cars ARE all the
same colour. They are all the same colour in every run, which is not the same claim.

**WHAT [[RLG-181]] CHANGED, AND WHAT IT DELIBERATELY DID NOT.** The assignment named one body -
`optBody === 'CRUISER'` - so a player in the interceptor could never be the car the force matched
itself to. It asks `inForce()` now, which reads the BODY record, the same question the light bar and
the siren ask. That changes no pixel, because nothing reads the result; it stops the dead line from
being wrong for the day somebody wires it up.

**TWO ANSWERS, AND THEY ARE NOT THE SAME SIZE.** Wire it up - the cop sprites would have to be built
per run, or built twice and chosen between, which is real work at boot. Or delete the state and the
comment, and let the fixed colours be the honest description of what the game does. The second is
one line. Do not leave it as it is, because a comment stating a rule the code does not implement is
the kind of thing a later session believes.

So the owner's rule (one colour per run for all road police, from the regular police colours including locked ones, never iridescent) is not in the game yet.
