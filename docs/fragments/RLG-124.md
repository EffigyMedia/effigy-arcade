### RLG-124 — mirror-rain-test has three checks failing on the shipped build and it is not the weather
- **RULED 2026-08-31T17:50:52-04:00** — FOUND, NOT FIXED, AND IT PREDATES TODAY. While building [[RLG-108]] the mirror harness was run and three of its checks were already red: "the frozen dry scene holds still between samples", "with no particles the check goes red, so it measures them and nothing else", and "and the snow check goes red with the particles off as well". IT WAS CONFIRMED PRE-EXISTING by stashing the day's work and running it against the last commit, where the same three fail with the same shape. So it is not the count-in change, not the rolling start and not the steering rate.

WHAT THEY ALL SAY IS ONE THING: THE GLASS IS NOT STILL WHEN IT IS SUPPOSED TO BE. Every one of those checks works by freezing the scene, grabbing the pane, and asking whether the only thing that changed is the thing under test. Measured while building RLG-108's own check, a pane that should have been unchanged between two grabs read anywhere from 0.07 to 27.47 per cent of its pixels moving - on the same build, minutes apart.

THE LIKELY CAUSE IS TODAY'S OWN LESSON, and it should be tested before anything else. [[RLG-055]] cost five faults in one measurement and four of them were the same mistake: a controlled variable set once before the loop that the running game quietly took back. This harness sets the weather dry and sweeps the road ONCE and then samples for several hundred milliseconds. Interstate spawns traffic on a timer, and a car that appears between two sweeps is DRAWN before the next sweep removes it - a car in the mirror is a large change to a small pane.

RLG-108's OWN CHECK WORKS AROUND IT RATHER THAN FIXING IT, and says so: it re-asserts the dry empty road every few frames AND takes the MEDIAN of nine samples, which is the idiom this same file established for the weather and for the same reason - "a maximum is exactly the statistic a single contaminated frame can walk away with". With that it reads 1.12 per cent for a board against 0.01 per cent for an unchanged world. THE WEATHER CHECKS ABOVE IT WERE NOT CHANGED, because they are not this unit's and a harness whose numbers are being questioned is not one to edit in passing.

WHAT TO DO. Apply the same two things to the weather checks - hold the controls every frame, take a median - and see whether all three go green. If they do not, the next question is whether the mirror genuinely redraws something every frame that it should not, and the instrument is then sound enough to ask it with.

AND CHECK WHETHER IT EVER PASSED. It is worth knowing whether these three have been red since the file was written or went red later, because the answer decides whether this is a harness that never worked or a regression nobody was watching for. `git log` on the file and a run at the commit that added it will say.
