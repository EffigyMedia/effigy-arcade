### UNT-289 - The ambulance has a face in the mirror, and the guard stops carrying a list

- Routing class: `defect` -> **claude-opus-5**, effort **high**. Bias 1. Finding the cause is the work, and a wrong guess costs a second pass. ([[RLG-092]])
- Opened for: [[RLG-228]]
- Opened by `unit.py`. **The identity exists before the first edit** ([[RLG-097]]), so the snapshot has somewhere to go.
- **CLOSED 2026-09-12T21:34:22-04:00** - v0.14.4. The mirror picks a traffic vehicle's face out of FRONT_SP by its type, and that cache is built from a list of kinds written before the ambulance existed - so the lookup missed, the racer branch was skipped because traffic carries a type and no body, and the mirror fell through to the defensive grey lozenge whose own comment claims nothing in the fleet still needs it. The BACK was always right, which is why it was only ever seen in the mirror: the road pass falls back to SP[type] and the mirror's pick has no such fallback. THE GUARD WAS FIXED FIRST AND WATCHED FAILING. face-test.py existed for exactly this defect, after it had already happened three times, and carried its own hand-written list of traffic kinds with neither the ambulance nor the hatch in it. It enumerates from API.trafficKinds() now, which is new and answers Object.keys(TYPE_VMAX) - the oracle is that table because the SPAWNER reads it, so a kind missing from it cannot be put on the road at all. The first run after that change reported the owner's defect in the owner's words, and the count went from 33 vehicles to 40. Then FRONT_SP.ambulance was built, one livery, from the same paint SP.ambulance uses so the two ends are one vehicle. The gate in paintRigFront that holds the van's newer face off the ambulance was left alone deliberately - the owner's ambulance reference is a different face again and is not built. face-test gained --falsify, which serves that one line out and reports the ambulance as a block. NOT FIXED: TYPE_VMAX carries hatch twice, 0.58 and 0.55; the later wins so the value is right and the dead key is invisible.
