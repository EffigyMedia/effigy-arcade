### RLG-249 — Non-racing vehicles are not unlockable, and the garage card is one measured size
- **RULED 2026-09-14T21:56:47-04:00** — **DECIDED, NOT STARTED.** Owner, 2026-09-14: *"If we get rid of unlocking regular traffic vehicles that'll Save us from having to derive the proper size cards in the garage as well as offer uniquely omitted menu choices. So let's just get rid of unlocking the non-racing vehicle vehicles. That means we can get rid of the hiding toggle we can measure all the reasonable cars and pick an appropriate single size for the garage card that leaves vehicle vehicles all the same relative size without extra unneeded, buffer or padding on the card. We also don't need a special subset menu design to handle those cars."*

## WHAT TO BUILD

1. **The non-racing vehicles are no longer unlockable or drivable.** These are the traffic bodies the secret unlocks gave the player (the utility class: VAN, SEMI, CAB, PICKUP, AMBULANCE; confirm the list against `isNovelty` and the class table before cutting). The garage never lists them.
2. **The WORK VEHICLES toggle is removed** (`optNovelty`, `noveltyOwned` and its button). This retires the toggle note carried into [[RLG-223]] item 2.
3. **One garage card size.** Measure the cars that remain at the shared scale ([[RLG-246]]) and choose a single card height that fits the tallest with no spare buffer. The `big` card tier ([[RLG-087]]) and the per-tier reserve go, because no oversized body reaches the garage.
4. **No special menu subset for those cars.** Any garage branch that exists only for a utility body goes.

## THINGS THAT MUST NOT BREAK

- A save that has a utility body selected, or holds its unlock flag, must still load onto a car the player owns. `enforceCarRules` is the place.
- The bodies stay in the game as TRAFFIC. Only the player's access goes.
- With PICKUP out of the garage, the shared scale is set by a racing car, so every garage car gets larger. Re-measure.
- Harnesses that exercise the novelty cars (`novelty-test.py`, and any class, resort or garage harness that expects them) must be changed with the build, not left red.

**Supersedes the order of the 2026-09-14 queue:** build this before RLG-248, because it changes the garage scale just built.
